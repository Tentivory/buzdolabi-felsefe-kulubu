# Buzdolabı Felsefe Kulübü

## Dünyanın En Ciddi ve En Gereksiz Projesi

Hoş geldiniz sevgili varoluşsal kriz yaşayan yiyecek sevenler!

Bu repository, buzdolabınızın kapağı kapandıktan sonra içeride neler olup bittiğini bilim ve felsefe ışığında açıklayan **tek** gerçek kaynaktır. Domates ile salatalık arasındaki "kim daha yeşil" tartışması artık sır değil.

### Neden Bu Proje Var?

Çünkü bir gün biri "Acaba süt neden hep en arkada duruyor?" diye sordu ve insanlık cevap veremedi. Biz cevap verdik. Hem de Python ile.

### Kurulum

```bash
pip install nothing  # çünkü hiçbir şeye ihtiyacı yok, her şey içinde zaten var
python buzdolabi.py
```

### Özellikler

- Gerçek zamanlı yiyecek diyalogları
- Varoluşsal sorular ("Ben neden burada duruyorum?")
- Peynirin Nietzsche alıntıları
- Yumurtanın kırılma korkusu
- %100 çalışan kod (şaka değil, gerçekten çalışıyor)
